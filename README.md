# Implementing a Secure Network Architecture for a Large Enterprise

> ⚠️ **Disclaimer:** This project is a comprehensive security design and implementation framework developed for educational and advisory purposes. Lab exercises were conducted on authorised platforms (HackTheBox). Do not replicate against any system without explicit written permission.

## Overview

A complete enterprise network security architecture project for a multinational enterprise with multiple branch offices and remote users. Combines 14 strategic documents with 3 hands-on cybersecurity laboratory exercises — including HackTheBox and OWASP validation labs.

## Deliverables — 14 Documents

| # | Document | Focus |
|---|---|---|
| 1 | Network Architecture Assessment Report | Current state, risks, gaps |
| 2 | Network Architecture Design Document | Full layered security design |
| 3 | Perimeter Security Configuration Guide | Firewall, IDS/IPS, DMZ |
| 4 | Network Segmentation Plan | VLANs, zones, microsegmentation |
| 5 | Secure Remote Access Strategy | VPN, zero-trust remote access |
| 6 | Endpoint Security Plan | EDR, patching, device hardening |
| 7 | IAM Configuration | RBAC, least privilege, directory integration |
| 8 | Data Encryption Strategy | TLS, at-rest encryption, key management |
| 9 | Monitoring and Logging Plan | SIEM, log collection, alerting |
| 10 | Policy and Compliance Documentation | Governance, standards alignment |
| 11 | Incident Response Plan | Detection, containment, recovery |
| 12 | Lab 1 Report — Network Security Essentials (HTB) | 42-screenshot HackTheBox lab |
| 13 | Lab 2 Report — Secure Network Architecture | Firewall & zone-based security |
| 14 | Lab 3 Report — OWASP Identification & Authentication Failures | OWASP Top 10 validation |

## Hands-On Labs
